# TokenBrice

I build open-source stablecoin and DeFi research infrastructure.

Current focus:

- [Pharos](https://pharos.watch) - stablecoin risk dashboard for peg health, liquidity quality, issuer controls, dependencies, lifecycle coverage, and public data access.
- [PharosVille](https://pharosville.pharos.watch/) - live maritime visualization of Pharos stablecoin market signals.
- [Polaris docs](https://tokenbrice.github.io/polaris-docs/) - git-native user documentation for Polaris Finance.
- [tokenbrice.xyz](https://tokenbrice.xyz) - bilingual FR/EN writing on DeFi, privacy, and decentralized systems.

I care about infrastructure that makes risk, censorship resistance, fraud resistance, and transparency legible without requiring custody, wallets, or opaque SaaS.
